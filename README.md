# 📱 Qoldas — Мобильное приложение для изучения казахского жестового языка

**Qoldas** — это многофункциональное образовательное приложение, разработанное на **Flutter**, которое помогает пользователям освоить казахский жестовый язык. В приложении реализованы мультиязычный интерфейс, интерактивные видеоуроки, тесты, отслеживание прогресса, синхронизация с Firebase и персонализированный пользовательский профиль.

---

## ✨ Основные функции

### 🧩 Тематическое обучение
- Курсы организованы по темам: **Семья**, **Природа**, **Казахская культура**, **Еда**, **Общение**.
- Каждая тема доступна на трёх языках: `Русский`, `Қазақша`, `English`.
- Данные загружаются из Firestore и кэшируются локально на устройстве через `SharedPreferences`.

### 📈 Уровни сложности
- Три уровня: `Лёгкий`, `Средний`, `Продвинутый`.
- Пользователь может фильтровать курсы по уровню.
- Выбранный уровень сохраняется индивидуально для каждой темы.

### 🎬 Уроки: Видео + Вопросы
- Каждый модуль состоит из шагов: несколько `видео` и блок `вопросов` после.
- Продвижение вперёд возможно только при правильных ответах.
- Видео воспроизводятся автоматически.

### 🧠 Тестирование
- После прохождения всех шагов открывается финальный тест.
- Тест оценивается в процентах.
- Вопросы и ответы поддерживают мультиязычный формат (из Firestore).

### 📊 Прогресс пользователя
- Прогресс сохраняется в `Firestore` по `userId`.
- Учитываются завершённые шаги, пройденные уроки и точность по тестам.
- В профиле отображается персональная статистика по каждому курсу.

### 🧑 Профиль и настройки
- Возможность изменить `никнейм`, `имя`, `фамилию`, `аватар`.
- Поддержка переключения языка интерфейса и темы приложения.
- Доступны `светлая` и `тёмная` темы.

### 💳 Планы (в разработке)
- Бесплатный и подписной доступ.
- Возможность подачи документов на бесплатный доступ для пользователей с инвалидностью.

## 📁 Структура проекта

### `assets/`
- `avatars/` — изображения для аватаров.
- `icon/` — иконки приложения.

### `lib/models/`
- Модели: курс, тема, уровень, секция, урок, шаг, вопрос, пользователь.

### `lib/screens/`
- Экраны: `home/`, `levels/`, `courses/`, `lessons/`, `plans/`, `profile/`, `admin/`.

### `lib/services/`
- Работа с Firestore, прогрессом, шагами, тестами, настройками.

### `lib/widgets/`
- Карточки, фильтры, прогресс-бары, видеоплееры и другие переиспользуемые компоненты.
