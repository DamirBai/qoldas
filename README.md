# 📱 Qoldas — Мобильное приложение для изучения казахского жестового языка

**Qoldas** — это многофункциональное образовательное приложение, разработанное на **Flutter**, которое помогает пользователям освоить казахский жестовый язык. В приложении реализованы мультиязычный интерфейс, интерактивные видеоуроки, тесты, слежение за прогрессом, синхронизация с Firebase и настраиваемый пользовательский профиль.

---

## ✨ Основные функции

### 🧩 Тематическое обучение
- Курсы организованы по темам: **Семья**, **Природа**, **Казахская культура**, **Еда**, **Общение**.
- Каждая тема поддерживает 3 языка: `Русский`, `Қазақша`, `English`.
- Загружается с Firestore в реальном времени.

### 📈 Уровни сложности
- Три уровня: `Лёгкий`, `Средний`, `Продвинутый`.
- Фильтрация курсов по уровню.
- Уровень сохраняется для каждой темы отдельно.

### 🎬 Уроки: Видео + Вопросы
- Каждый модуль состоит из шагов: несколько `видео` и блок `вопросов` после.
- Пользователь продвигается, если ответит правильно.
- Поддержка автоматического воспроизведения.

### 🧠 Тестирование
- После прохождения всех шагов в уроке открывается финальный тест.
- Считается точность в процентах.
- Вопросы поддерживают мультиязычность.

### 📊 Прогресс пользователя
- Прогресс сохраняется в `Firestore` по userId.
- Учитываются: завершённые шаги, уроки, проценты по тестам.
- На странице профиля отображается статистика по каждому курсу.

### 🧑 Профиль и настройки
- Пользователь может изменить `никнейм`, `имя`, `фамилию`, `аватар`.
- Выбор языка и темы приложения.
- Поддержка `тёмной` и `светлой` темы.

### 💳 Планы (в разработке)
- Бесплатный и подписной тариф.
- Возможность подать документы на бесплатный доступ для людей с инвалидностью.

## 📁 Структура проекта

### `assets/`
- `i18n/` — JSON-файлы переводов.
- `avatars/` — аватары пользователей.
- `icon/` — иконки приложения.

### `lib/models/`
- Курсы, темы, уровни, секции, уроки, шаги, вопросы, пользователь.

### `lib/screens/`
- `home/`, `levels/`, `courses/`, `lessons/`, `plans/`, `profile/`, `admin/`.

### `lib/services/`
- Работа с Firestore, логика шагов и тестов, переводы, прогресс пользователя.

### `lib/widgets/`
- Виджеты карточек, фильтров, прогресс-бара, видеоплеера.

## 🚀 Установка и запуск

```bash
git clone https://github.com/твоя-ссылка/qoldas.git
cd qoldas
flutter pub get
flutter run
```

> Убедись, что установлены Firebase CLI и Android/iOS SDK.
